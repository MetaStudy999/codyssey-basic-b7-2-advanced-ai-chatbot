# B7-2 — 시작 전 지식 체크

이 문서는 B7-2 고도화 프로젝트를 시작하기 전에 **Project A 결과물과 Full-stack/Auth/REST/Deploy 역량이 준비되어 있는지** 확인하는 자가진단입니다. 공식 평가 점수는 아니지만, B7-1은 공식 구조상 필수 선행입니다.

## 선행 학습

- **필수 선행 미션:** B7-1
- **권장 선행 미션:** B4-2, B5-2, B5-3, B6-1
- **있으면 좋은 선행 지식:** REST, Auth/Ownership, 관계형 모델, Cloud Deploy, 기술 문서화

## 필수 확인

- [ ] B7-1(Project A)의 AI 챗봇 MVP가 준비되어 있다.
- [ ] B7-1의 주요 기능과 구조를 설명할 수 있다.

위 두 항목이 준비되지 않았다면 B7-1을 먼저 완료합니다. B7-2 공식 Mission이 Project A의 챗봇 기능을 기반으로 고도화하도록 요구하기 때문입니다.

## 자가진단

- [ ] REST API에서 URL, HTTP Method, Status Code의 역할을 대략 구분할 수 있다.
- [ ] 회원가입/로그인과 인증 토큰의 기본 흐름을 이해한다.
- [ ] Authentication과 Authorization/Ownership의 차이를 설명할 수 있다.
- [ ] 관계형 DB에서 사용자와 게시글/대화의 관계를 모델링해야 하는 이유를 이해한다.
- [ ] Frontend가 Backend API를 호출하는 흐름을 이해한다.
- [ ] 외부 접속 가능한 배포 환경과 환경변수/Secret 관리의 필요성을 이해한다.
- [ ] ERD, API 명세, Architecture Diagram이 각각 무엇을 설명하는 문서인지 알고 있다.

## 판단 방법

- **B7-1이 준비되지 않았다면 B7-2를 먼저 시작하지 않습니다.**
- B7-1이 준비되어 있고 대부분 `예`라면 `BEGINNER-GUIDE.md`로 진행합니다.
- 일부가 `아직`이라면 B4-2/B5-2/B5-3/B6-1의 관련 개념만 선택적으로 보충하면 됩니다.

> B4-2/B5-2/B5-3/B6-1은 **권장 선행**이며 모두 CLEAR해야 하는 것은 아닙니다.
